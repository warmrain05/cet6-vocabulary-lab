# 六级词汇研究室 V10 · 文字笔记优先版

这是一个可离线运行、可通过 GitHub Pages 发布的单文件静态网页。

## V10 改进

- 每个单词的「05 我的学习笔记」以**文字笔记**为主：输入英文词，回车或点击“添加到笔记”，下面自动显示词书中的**英文 + 中文释义**。
- 点击已收录词条即可跳转到对应单词详情，支持核心词/完全版跨范围跳转。
- 新添单词仍保持双向关联、去重和删除，兼容 V9 已保存的关联词。
- 下方保留独立文字编辑框，自动保存自己的例句和心得。
- 手写板默认折叠，可展开。**清空画板**改为立即清空并持久化，无需确认弹窗；支持撤销恢复。修复了异步恢复旧画面的问题。
- 保留两本词书、分类、137 组易混词、常用搭配、美式音标、收藏、主题与 JSON 导入/导出。

## GitHub Pages 部署

1. 将 `index.html`、`.nojekyll`、`README.md` 上传到你 GitHub 仓库的根目录。
2. 仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
3. 打开 Pages 显示的网址。无需安装 Node.js / npm。

## 数据安全与说明

- 个人笔记/手写/易混词保存在当前浏览器 localStorage，**不会自动同步到 GitHub 或另一台电脑**。更换域名、设备、浏览器前请使用网页底部「导出全部记录」，再导入。
- V9 旧数据的 localStorage 键名不变；在同一站点同一浏览器更新 V10，已有笔记可以继续读取。若从本地文件迁移到 GitHub Pages，应使用 JSON 导入导出。
- 词典未收录的自定义关联词仍可保存，但显示“词库未收录”，不会编造中文释义，也无法打开词条详情。
- 网站内置的原始词汇解释来自用户提供的第三方词表；公开发布前请核实你拥有转载/公开这些资料的权利，避免版权风险。
- 星级是学习优先级，不是近十年的实际考频。
